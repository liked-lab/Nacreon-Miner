# Диагностика отклонённых шар в Nacreon0.23.7

При запуске добавьте `--reject-log` в дополнительные параметры Flight Sheet или команду запуска. Журнал также можно включать и выключать во время работы.

Из каталога установленного майнера:

```sh
./nacreon-log on
./nacreon-log status
./nacreon-log off
./nacreon-log export
```

Одна команда экспорта:

```sh
./nacreon-log export
```

Команда покажет путь созданного файла. Выполняйте её от того же пользователя, от которого работает майнер. На HiveOS при необходимости используйте `sudo ./nacreon-log export`. Файл создаётся в текущем каталоге, который должен принадлежать этому пользователю и не быть доступным другим для записи.

Журнал ограничен по объёму и хранится в RAM. Экспорт включает подтверждённые отклонения, доступные сведения об устройстве и времени и очищенную причину пула. Недоступные сведения остаются неизвестными. Потерянное подтверждение не считается отказом. Кошельки, пароли, конфигурации и содержимое доказательств не экспортируются.
